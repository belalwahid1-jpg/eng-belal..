# Belal Wahid — Portfolio

A responsive personal portfolio built with plain HTML, CSS, and JavaScript. No build step or package installation is required.

## Run locally

Open `index.html` in a browser, or serve this folder with any static file server.

## Portraits

Your supplied images are included in `assets/`. `belal-wahid.jpg` is the hero portrait; the daylight photo is placed in the About section, and the evening photo is placed in Education. The Nahda University and Faculty of Computer Science logos appear with the education details. The section photos load lazily.

## Contact behavior

Email links open the visitor's email application. Phone and WhatsApp links use the supplied Egyptian mobile number. The social links open the supplied profiles in a new tab.
